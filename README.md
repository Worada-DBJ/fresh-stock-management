Fresh Stock Management System 
โปรเจกต์ระบบจัดการสต็อกสินค้าแบบ Full-stack ที่ทำขึ้นเพื่อช่วยจัดการของใช้ในครัวและติดตามวันหมดอายุ
ทำไมถึงทำโปรเจกต์นี้?
•	อยากช่วยแก้ปัญหาการลืมวันหมดอายุของของสดในครัว
•	เพื่อฝึกการเขียนระบบตั้งแต่ Frontend ไปจนถึง Backend และการออกแบบฐานข้อมูล
สิ่งที่ใช้ทำ (Tech Stack)
•	Frontend: ใช้ React กับ TypeScript ทำหน้าเว็บให้ลื่นไหล
•	Backend: ใช้ Nest.js (Node.js) จัดการระบบหลังบ้าน
•	Database: ใช้ MySQL (จัดการผ่าน phpMyAdmin) เก็บข้อมูลสต็อกทั้งหมด
•	Design: ออกแบบ UI ด้วย Tailwind CSS 
จุดเด่นของโปรเจกต์
•	Dashboard: ดูได้ทันทีว่าตอนนี้มีของอะไรเหลืออยู่บ้าง และอะไรกำลังจะหมดอายุ
•	Data Management: ออกแบบ API และฐานข้อมูลให้เชื่อมต่อกัน 
•	Redux Toolkit: ใช้จัดการสถานะข้อมูลในหน้าเว็บให้ทำงานได้เร็วขึ้น
